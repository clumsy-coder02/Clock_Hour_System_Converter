# 12-Hour and 24-Hour Clock Converter

A Python utility to convert between 12-hour and 24-hour time formats.

## Description

This program allows you to input a time and automatically converts it between 12-hour and 24-hour clock systems. It intelligently determines which format your input is in and provides the converted result.

## Features

- Convert from 12-hour to 24-hour format
- Convert from 24-hour to 12-hour format
- Input validation for hours (0-23) and minutes (0-59)
- Displays both the original time and converted time

## Usage

Run the program from the terminal:

```bash
python main.py or python3 main.py
```

Follow the prompts:

1. Enter the hours (0-23)
2. Enter the minutes (0-59)

The program will display your input time and the converted time in the appropriate format.

### Example

```bash
Convert between 12 and 24 hour clock system
Enter the current time:

Enter the hours (0-23): 14
Enter the minutes (0-59): 30

Current time: 14:30
Time in 12hr system: 2:30
```
